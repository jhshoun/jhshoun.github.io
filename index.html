Interactive curriculum vitae

This page is an exploration of an alternative way to visualize a resume. The traditional text resume doesn't give a sense of how different positions, skills, and projects relate over time. This view shows each of these over. Any of the items can be clicked to see details.

This was developed using the timeline component of the SIMILE Widgets project at MIT. It is a Javascript framework that displays timeline data from XML files. That probably betrays its age; more recent development would probably have used JSON. Here is an alternative version in another framework (that does use JSON data sets).

Use the mouse to drag the timeline or the scroll wheel pan left and right. Click any entry to display the information dialog.
